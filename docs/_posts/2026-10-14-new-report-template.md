# New Report Template! 

There's a new report template in town. This is not for academic reports like you'd submit at University; this is for business reports. White papers, Request for Proposal documents, proposals, and financial reports are all appropriate for this template. 

As usual, the [docs](/VimStar/writing/templates/) describe how to use the template, and there's a snippet to help you with the YAML headers. 

If you have any problems with the template, please submit an [issue](https://github.com/sez11a/VimStar/issues). 

Enjoy!
