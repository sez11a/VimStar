You can now set the body text font size in the Report template, so you have a bit more control over how your formal documents look.

The template used to hard-code the body text at 12pt, which was fine for most reports, but if you were writing a white paper or an RFP response with long paragraphs, it could feel a little tight.

Now you can set the body text size to whatever you like. Push it up if you need more room, or bring it down if you want something tighter.

The default is still 12pt, so nothing changes for reports that don't set it.

Head over to the [Templates docs](/writing/templates/) for the full details. Enjoy!
