As I build out VimStar, I wanted to be able to post what's getting updated, so here it is. This'll be a bigger update than normal, as I want to capture everything I've done since the site went up. 

- 2026-10-02: Standardize default template fonts to Libertinus Serif and Libertinus Sans. 
- 2026-10-01: Add WordStar's Save As command (Space-kt), now that we have the dialog box.
- 2026-09-30: Add a new, custom VimStar-only Save As dialog box for new files. The Telescope one was non-intuitive; this is much better.
- 2026-09-23: Fix all Typst templates; remove LaTeX templates. Typst handles all PDF formatting now. 
- 2026-09-21: Switch back to `nvim-treesitter`, as it's being maintained again.
- 2026-09-19: Added WordStar-like file picking on startup. 
- 2026-09-11: Book Template Enhancement: added copyright holder field. 
- 2026-09-09: Added Markdown snippets to make it easy to configure template YAML headers.
- 2026-09-09: New template: Business letter. 
- 2026-09-09: Book Template Enhancement: Users can now choose the fonts they wish for headings and body text.
- 2026-09-07: Book Template Enhancement: add dedication page and ISBN. 
- 2026-09-01: New template: submission format as an .odt (LibreOffice) file. Many publications require story submissions in .odt or .docx; this template formats your story automatically and exports it as an .odt. If you need .docx, you can further export the .odt to .docx. 
- 2026-08-19: Add a Telescope-based Save As dialog for new files. I'm trying to decrease the "papercuts" for new users of Neovim who are used to nice, polished file pickers.
- 2026-07-27: New template: story submission PDF. This is for writers submitting short stories to publications who want their stories formatted automatically in submission format. Fully documented on the [writing/templates](/VimStar/writing/templates) page. 
- 2026-07-25: Added graceful dependency checking. If you don't have an optional dependency installed (such as Yarn for Markmap) VimStar now tells you to install it to use the function, rather than displaying an error.
